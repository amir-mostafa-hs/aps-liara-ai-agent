# 01: Persian Chat Shell and Sidecar Console Layout

**What to build:**
A modern, Persian-first (RTL) split layout replacing the legacy static multi-step card view. On the right, an interactive virtualized chat stream capable of rendering text, Markdown, and custom interactive widgets. On the left, a persistent sticky sidecar console showing the live terminal output, active cloud services, and system connectivity badges.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] RTL layout with Vazirmatn / Shabnam font stack and Persian labels
- [x] Conversational chat stream on the right with user and agent message bubbles
- [x] Sticky left sidecar console with terminal viewer, service status cards, and minimize/expand toggle
- [x] Responsive behavior: collapses into tabbed drawer on mobile screens
- [x] Unit tests for chat message rendering and layout responsiveness
